# Clawd kaiju

Clawd, the Claude mascot, rigged and animated for the demo: a squat terracotta rounded blob with
two small dark eyes and two stubby block feet. No arms, tail, mouth or emblem, because the mascot
has none. Everything is generated by `kaiju.py` inside Blender, so there is no hand-made file to
keep in sync and no downloaded asset. `kaiju-contact-sheet.jpg` shows the current build.

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/kaiju.py -- \
  --out public/models/kaiju.glb --sheet tools/blender/kaiju-contact-sheet.jpg
```

Needs Blender 4.4 or newer (5.2 was used). The GLB is committed, so nobody else has to run
Blender unless they change the model. Add `--shots /tmp/kaiju-shots` to keep the individual
preview frames. `--style kaiju` builds the earlier Godzilla-style body in the Claude palette
(cream belly, glowing plates, Claude starburst, mascot face) on the same rig.

## What is in the GLB

- One skinned mesh, about 1.2k vertices, materials `KaijuBody` (terracotta) and `KaijuClaw`
  (charcoal eyes). The kaiju style adds `KaijuBelly`, `KaijuGlow` and `KaijuEye`; the actor pulses
  the emissive ones on a roar when they exist.
- A 25-bone armature shared by both styles: hips, spine, chest, neck, head, jaw, two arms, two
  legs, five tail bones. For Clawd only the spine chain and legs carry geometry.
- Six clips, all in place (no root motion). The behaviour script moves the model.

| Clip   | Length | Loops | Events (normalised time)           |
|--------|--------|-------|------------------------------------|
| Idle   | 3.0 s  | yes   | none                               |
| Walk   | 1.5 s  | yes   | footstep left 0.30, right 0.80     |
| Rise   | 3.0 s  | no    | none; played backwards to submerge |
| Attack | 2.0 s  | no    | hit 0.45 (a body slam)             |
| Roar   | 2.5 s  | no    | roar 0.30 (rears back)             |
| Stomp  | 1.5 s  | no    | hit 0.58                           |

Clawd is about 4.8 units tall and faces +Z after export. `KaijuActor` scales it to a height in
metres (300 by default) and uses `rotation.y` as the heading.

## Changing it

- Proportions: `joints_clawd()` holds the joint positions, `build_mesh_clawd()` the parts.
- Animation: each clip is a function of normalised time that sets rotations about armature-space
  axes (the `Pose` docstring says what each axis means), sampled every two frames. A few
  amplitudes switch on `STYLE` because the squat body needs a shallower crouch and a longer lunge.
- If you change a clip length or an event time, update `KAIJU_CLIPS` in
  `src/simulations/kaiju/KaijuBehaviour.ts` to match.
- Re-run the command above and look at the contact sheet before committing.
