# Claude kaiju

A rigged, animated kaiju in the Claude palette with a Claude-mascot face: rounded-box head like
the Claude Code mascot, big dark eyes with highlights, a cream muzzle and smile, terracotta hide,
cream belly, charcoal claws, glowing cream dorsal plates and a glowing Claude starburst on the chest. Everything is
generated by `kaiju.py` inside Blender, so there is no hand-made file to keep in sync and no
downloaded asset with a licence to check. `kaiju-contact-sheet.jpg` shows the current build.

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/kaiju.py -- \
  --out public/models/kaiju.glb --sheet tools/blender/kaiju-contact-sheet.jpg
```

Needs Blender 4.4 or newer (5.2 was used). The GLB is committed, so nobody else has to run
Blender unless they change the model. Add `--shots /tmp/kaiju-shots` to keep the individual
preview frames.

## What is in the GLB

- One skinned mesh, about 5k vertices, five materials named `KaijuBody`, `KaijuBelly`,
  `KaijuClaw`, `KaijuGlow`, `KaijuEye` (the eye highlights). The actor pulses the two emissive ones on a roar.
- A 25-bone armature: hips, spine, chest, neck, head, jaw, two arms, two legs, five tail bones.
- Six clips, all in place (no root motion). The behaviour script moves the model.

| Clip   | Length | Loops | Events (normalised time)           |
|--------|--------|-------|------------------------------------|
| Idle   | 3.0 s  | yes   | none                               |
| Walk   | 1.5 s  | yes   | footstep left 0.30, right 0.80     |
| Rise   | 3.0 s  | no    | none; played backwards to submerge |
| Attack | 2.0 s  | no    | hit 0.45                           |
| Roar   | 2.5 s  | no    | roar 0.30                          |
| Stomp  | 1.5 s  | no    | hit 0.58                           |

The model is about 10 units tall and faces +Z after export. `KaijuActor` scales it to a height
in metres and uses `rotation.y` as the heading.

## Changing it

- Proportions: edit the joint positions at the top of the script and the parts in `build_mesh()`.
- Animation: each clip is a function of normalised time that sets rotations about armature-space
  axes (the `Pose` docstring says what each axis means), sampled every two frames.
- If you change a clip length or an event time, update `KAIJU_CLIPS` in
  `src/simulations/kaiju/KaijuBehaviour.ts` to match.
- Re-run the command above and look at the contact sheet before committing.
